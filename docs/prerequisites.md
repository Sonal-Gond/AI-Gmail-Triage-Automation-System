# Prerequisites

Set these up before configuring any of the four workflows.

## Accounts needed
- Zapier
- Gmail
- OpenAI (ChatGPT API key)
- Google Apps Script
- Google Sheets
- Pinecone

## Slack setup

Create one Slack workspace, then create the following **public channels**:

- `engineering-department`
- `billing-department`
- `feature-request-department`
- `general-department`
- `solution-priority`

## General steps for using any Zapier template

1. Open the template link.
2. Click **"Try it"**.
3. Sign in to Zapier if prompted.
4. Zapier creates a copy of the template in your workspace.
