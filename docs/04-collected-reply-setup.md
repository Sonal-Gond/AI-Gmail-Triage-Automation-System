## App Configuration

### Webhook
1. Open the Webhook node → **Configure**
2. Copy the generated webhook URL
3. Paste this webhook URL into **Template 3's** Slack API Request node (Body section)

### Gmail
Open the Gmail node → **Setup** tab → **Account** → select your Gmail account.

## Publish
Once configured, click **Publish**.
