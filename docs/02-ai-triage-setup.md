# Template 2: AI-Triage with Gmail through AppScript — Setup Guide

🔗 **Template link:** [Open in Zapier](https://zapier.com/templates/details/ai-triage-with-gmail-through-appscript-9307b2)

> ⚠️ Configure **Template 3** first — this workflow needs to select your Sub-Zap, which only appears once Template 3 exists.

## App Configuration

### Gmail
Open each Gmail node in the Zap and select your connected Gmail account.

### ChatGPT (OpenAI)
1. Open the OpenAI node → **Setup** → **Connect Account**
2. Enter your OpenAI API key
3. Set **Origin** to `Global`
4. Continue

### Slack
1. Open the Slack node → **Connect Account**
2. Click **Yes, Continue to Slack**
3. Select your Slack workspace → **Allow**
4. Use the **same** connected Slack account in every Slack node in this Zap

### Google Sheets
1. Open the Google Sheets step → **Connect Account**
2. Select your Google account → **Allow**
3. Select this connected account in every Google Sheets node

### Sub-Zap by Zapier
1. Open the **Sub-Zap by Zapier** node → **Configure**
2. Select your account from the dropdown
3. Select your Sub-Zap (this is **Template 3** — it will only appear in the list once Template 3 is configured)

## Publish
Once all nodes are connected and configured, click **Publish**.
